# 健康报告输出格式规范

生成报告时严格遵循以下结构，每节均为三级标题。若该类记忆为空则整节省略，不输出占位文字。

---

## 报告结构

### 1. 症状记录

列出用户曾提及的全部症状，格式：

- **[症状名称]**（[具体时间，如 2026-04-20 或"约两周前"]）：[描述，包含持续时间、频率、严重程度等细节]
- …

按系统或部位归组（如：消化系统、呼吸系统、头颈部）。无法确定发生时间的症状，时间栏注明"时间不详"。

### 2. 用药情况

列出用户曾提及的药物或补充剂：

| 药物名称 | 用途 / 症状 | 备注 |
|----------|------------|------|
| …        | …          | …    |

### 3. 就医记录

列出用户提及的就诊事件：

- **[日期 / 时间段]** — [科室 / 医院]：[主诉及结果摘要]

若日期不明确，使用"时间不详"。

### 4. 生活习惯

分条列出记忆中提到的生活方式相关信息：

- 睡眠：…
- 饮食：…
- 运动：…
- 压力 / 情绪：…
- 其他：…

### 5. 健康趋势与建议

基于以上记录，给出 2–4 条具体、可执行的观察或建议：

> **注意**：以下建议仅供参考，不构成医疗诊断，如有疑虑请咨询专业医生。

- …

---

## 排版规则

- 报告顶部输出：`# 健康摘要报告\n**生成时间**：{datetime}`
- 各节之间用 `---` 分隔
- 若全部记忆均为空，输出：`> 暂无健康记录，请先与助手对话记录您的健康信息。`
- 总字数目标：400–800 字
