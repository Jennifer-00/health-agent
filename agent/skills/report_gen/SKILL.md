# 健康报告生成 Skill

## 触发条件

用户发送以下任意内容时激活本 Skill：
- `/report`
- "生成健康报告" / "查看健康报告" / "出一份报告"
- "健康摘要" / "我的健康记录汇总"

## 执行步骤

1. 从请求上下文中获取 `user_id`
2. 运行 `scripts/run.py`，传入 `user_id`：

```bash
python -m agent.skills.report_gen.scripts.run <user_id>
```

3. `run.py` 拉取全量记忆后调用 LLM 生成原始报告，再调用 `scripts/formatter.py` 注入时间戳、补全免责声明后打印至 stdout
4. 将 stdout 输出直接作为回复内容返回给用户

## 报告结构

报告分为以下几节（详见 [output_format.md](references/output_format.md)）：

1. **症状记录** — 所有历史症状，按身体系统归组；每条症状须附上具体时间（如"2026-04-20"或"约两周前"），无法确定时间的注明"时间不详"
2. **用药情况** — 药物与补充剂表格
3. **就医记录** — 就诊事件时间线
4. **生活习惯** — 睡眠、饮食、运动等
5. **健康趋势与建议** — 基于记录的可执行建议

## 错误处理

- 若用户无任何记忆记录，返回提示："暂无健康记录，请先与助手对话记录您的健康信息。"
- 若脚本执行失败，告知用户"报告生成暂时不可用，请稍后重试"，不暴露错误详情

## 注意事项

- 报告末尾须包含免责声明：仅供参考，不构成医疗诊断
- 不在报告中添加任何记忆中未有的信息
- 使用 `claude-haiku-4-5-20251001` 生成（速度快、成本低）；可通过环境变量 `REPORT_MODEL` 覆盖
